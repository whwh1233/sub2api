# 首页请求流动效预览

当前设计稿，尚未接入正式首页。没有后端依赖，也不会发送真实模型请求。

- `animation.html`：可编辑的动画片段，包含 Canvas、样式与脚本。
- `index.html`：独立演示页，可直接用浏览器打开；由动画片段生成。

桌面采用裁切的大圆弧构图，请求沿弯曲路径流动并随机到达圆弧。实际碰撞后，局部橙色光缓慢从内向外扫过细碎纹理，再逐渐消退。圆弧没有预置固定光点。

支持暂停、窄屏布局、减少动态效果偏好，以及页面不可见时暂停绘制。

本地预览：在本目录执行 `python3 -m http.server 8769 --bind 127.0.0.1`，访问 `http://127.0.0.1:8769/`。
